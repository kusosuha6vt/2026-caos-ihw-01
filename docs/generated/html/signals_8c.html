◆ signals_install()

int signals_install ( void )

Install SIGINT/SIGTERM handlers and ignore SIGPIPE.

Uses sigaction for both interruption handlers and ignores SIGPIPE so broken console pipes are handled as ordinary output failures.

Returns
0 on success, -1 after reporting a sigaction failure to stderr.
