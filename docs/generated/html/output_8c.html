Write one event snapshot and apply the configured display delay.

Formats a snapshot from current records, increments seq, writes synchronously and then applies presentation pacing.

Parameters
[in,out]simulationCurrent model; sequence and I/O status may change.
kindInternal JSON-safe event name.
messageInternal JSON-safe human description.
slotValid visitor slot, or -1 for no visitor.
paintingZero-based painting index, or -1 for no painting.
durationEvent duration in logical milliseconds, or 0 if unused.

Writes are synchronous; failures set the model's io_failed flag. Strings must need no JSON escaping. Pacing does not change logical time.

void output_summary ( struct Simulation * simulation,

uint64_t pending_entrance,
uint64_t pending_painting )

Write journal, painting statistics and the final summary.

Aggregates painting statistics, appends the journal first, then emits painting statistics and summary. Output failure updates the model status.

Parameters
[in,out]simulationModel after all visits have ended or been cancelled.
statusInternal status: completed, interrupted or failed.
pending_entranceCensored entrance-wait sum measured before cancellation.
pending_paintingCensored painting-wait sum measured before cancellation.

Wait sums are logical milliseconds. I/O failures set io_failed and change the emitted summary status to failed.
