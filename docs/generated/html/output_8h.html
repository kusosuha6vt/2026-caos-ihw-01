int output_close ( Simulation * simulation)

Close the event log if enabled.

Parameters
[in,out]simulationModel holding the log descriptor.
Returns
0 on success, -1 after reporting a close failure.

A successful close resets log_fd to -1; failure is reported to the caller so shutdown can return a nonzero exit status.

Write one event snapshot and apply the configured display delay.

Parameters
[in,out]simulationCurrent model; sequence and I/O status may change.
kindInternal JSON-safe event name.
messageInternal JSON-safe human description.
slotValid visitor slot, or -1 for no visitor.
paintingZero-based painting index, or -1 for no painting.
durationEvent duration in logical milliseconds, or 0 if unused.

Writes are synchronous; failures set the model's io_failed flag. Strings must need no JSON escaping. Pacing does not change logical time.

Formats a snapshot from current records, increments seq, writes synchronously and then applies presentation pacing.
